# SimpleRecharge

## Reasoning
Feeling like the game's too hard? Want to play around with funny items but your meta teammates are angry? This mod might help you out!

## Features
`SimpleRecharge` will recharge your items in a certain interval and after each extraction. You can configure the charge given, the time interval and whitelist or blacklist items that will be recharged.
You can get the names of items present in the scene by pressing `F1` or list items that pass the filter using `F2`.

## Installation
Install the mod using r2modman or Thunderstore.

Manual installation: place `SimpleRecharge.dll` in `BepInEx/plugins/`.

## Configuration
The mod comes with the following configurable options:

Periodic recharge amount (some amount)
Interval between charges (seconds)
After extraction recharge amount (some amount)
List of items (item names separated by commas)

## Supported items
Should support all modded and vanilla equipment.
