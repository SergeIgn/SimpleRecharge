# First-REPO-Mod
First project, First modification for REPO game.

This mod recharges chosen items every 30 seconds (small charge) and after every extraction completion (large charge).


Patched functions are: ExtractionPoint.DestroyAllPhysObjectsInHaulList, 
ExtractionPoint.ActivateTheFirstExtractionPointAutomaticallyWhenAPlayerLeaveTruck,
RunManager.ChangeLevel
